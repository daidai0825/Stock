## M-01：QuoteDTO 序列化正號 + 字串精度

**修了什麼**：
- 新增 `SignedDecimalSerializer`：正值/零值補 `+` 前綴，負值保留 `-`，輸出 JSON string
- 新增 `PlainDecimalSerializer`：純字串輸出，不變號
- `QuoteDTO` 各 BigDecimal 欄位加 `@JsonSerialize`：`change`/`changePercent` 用 Signed；`price`/`previousClose`/`open`/`high`/`low` 用 Plain

**為何選方案 A**：DTO 內部仍為 BigDecimal，Convertor 計算邏輯零改動；序列化規則集中在 Serializer，職責清晰，後續若前綴邏輯變更只改一處。

**測試結果**：`QuoteDTOSerializationTest` 3 cases 全通過（正值/負值/零值）

## B-01：Spring 6.1+ RestClientConfig 編譯 Blocker

**修了什麼**：
- `RestClientConfig.buildRequestFactory()` 移除 `factory.setReadTimeout(int)`（Spring 6.1+ 已刪除）
- 改用 Apache HttpClient 5 `RequestConfig.setResponseTimeout(Timeout.ofMilliseconds(...))` 設定讀取逾時，語義等效

**為何此方案**：`ResponseTimeout` 是 HttpClient 5 對應 read timeout 的正確 API，timeout 行為完全保留（10s），連線池設定不受影響。

**測試結果**：`./mvnw clean compile` 無錯誤；stock-quote 模組測試進入執行階段，既存 `UnnecessaryStubbingException` 為 Round 2 前已存在的問題，不在本次範圍內。
