## 本波新增 TD

### TD-4：KLineChart E2E 測試缺口

**類別**：測試缺口
**優先級**：中
**原因**：
lightweight-charts 依賴 Canvas API，jsdom 無法模擬，Wave B 單元測試中 KLineChart 以 mock 替代。
需在 E2E 環境（Playwright + 真實瀏覽器）覆蓋：
- Candlestick 資料正確渲染
- resize 觸發重繪（ResizeObserver）
- unmount 後 `chart.remove()` 無記憶體洩漏
- 週期切換後資料更新

**預計解決波段**：Wave B QA 階段（Quincy / Quinn）
**負責人**：Quincy / Quinn（E2E 腳本），Felix 提供測試場景

### TD-5：MSW Service Worker 公開檔案未初始化

**類別**：Dev 環境設定
**優先級**：低
**原因**：
`public/mockServiceWorker.js` 需執行 `npx msw init public/ --save` 才能產生，
未納入 CI 自動化，新進開發者 clone 後瀏覽器 MSW 可能不生效。

**解決方式**：
在 `package.json` 加入 postinstall 或 prepare script：
```json
"msw:init": "msw init public/ --save"
```

**預計解決波段**：Wave B DevOps 階段或下次 onboarding 時
**負責人**：Linus（Library 工程師）

### TD-6：React Router v6 future flags warning

**類別**：技術升級
**優先級**：低
**原因**：
React Router 6 → v7 future flags（`v7_startTransition` / `v7_relativeSplatPath`）
在每次測試輸出 warning，Wave A 已知，Wave B 延續。

**解決方式**：
在 AppRouter BrowserRouter 加入 future props：
```tsx
<BrowserRouter future={{ v7_startTransition: true, v7_relativeSplatPath: true }}>
```

**預計解決波段**：Wave C（依 @types/react-router-dom 版本確認 props 型別）
**負責人**：Felix
