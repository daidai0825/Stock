## 🔴 Linus 提出的 Top 風險

### R-Linus-1：TWSE / MOPS 沒有官方 API 合約 ⚠️
- **影響**：MOPS 重大訊息需 HTML scraping，網頁結構一改即崩
- **無生產級 Java SDK**：必須自寫 `TWSEClient` / `OTCClient` / `MOPSClient`
- **預估開發成本**：~3 人週
- **緩解**：
  - 抽象 `MarketDataPort` 介面，實作可換（未來改付費 API 容易）
  - 大量 unit test 鎖定 response schema
  - 建立「資料源健康檢查」daily smoke test
  - 排版異動偵測 + 自動 issue 通知

### R-Linus-2：Easy Rules 維護停滯
- **影響**：CVE 修補可能需自 patch
- **緩解**：用 Adapter pattern 包裝（已採納），可在 1 週內切換到 Drools

### R-Linus-3：Spring Boot 版本鎖定
- **建議**：鎖定 3.3.13（LTS-like 穩定版），避免 3.4.x 早期 bug

## 架構成果概覽

### 後端
- **Java 21 + Spring Boot 3.3.13**
- **14 Maven module**（5 基礎 + 10 業務 + 1 boot）
- **Modular Monolith** 部署
- **PostgreSQL 16**（Docker）+ **Redis 7**（Docker）
- 11 資料表（含 `audit_logs` 新增 + `score_results` 季度分區）
- 8 處設計模式應用
- 38 個直接後端依賴

### 前端
- **React 19 + TypeScript 5 + Vite 5**
- **Ant Design 5** + **TradingView Lightweight Charts**
- **Zustand** 狀態管理 + **TanStack Query** API 快取
- 24 個直接前端依賴

### 資料源策略
- 自寫 TWSEClient / OTCClient / MOPSClient（基於 Spring WebClient）
- 抽象 `MarketDataPort` 介面留 future-proof
- Redis 快取 + 排程批次降低源端壓力
