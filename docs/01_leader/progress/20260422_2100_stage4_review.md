## 🔴 Blocker（Wave 2 / Wave B 啟動前必修）

### BE-01：MemberMapper.insert() 用 @Select 執行 INSERT
- **檔案**：`backend/stock-member/.../MemberMapper.java`
- **問題**：用 `@Select` 註解跑 INSERT 語句，MyBatis 行為未定義；同檔 `UserPreferenceMapper` 已正確示範 `@Insert`
- **修正**：改 `@Insert` 回 `int` affected rows
- **負責人**：Bruno
- **預估**：30 分鐘

### BE-02：JWT 解析 catch-all 吞掉 ExpiredJwtException
- **檔案**：`backend/stock-member/.../MemberController.java`
- **問題**：catch-all 吞 `ExpiredJwtException`，導致 `TOKEN_EXPIRED(3002)` 永遠不會回，前端無法觸發 refresh 流程
- **修正**：拆開 catch，先攔 `ExpiredJwtException` 回 3002，再攔其他 JWT 例外回 3003
- **負責人**：Bruno
- **預估**：1 小時

### BE-03：AuditAspect 讀 MDC.get("userId") 但全程未 put
- **檔案**：`backend/stock-common/.../AuditAspect.java`
- **問題**：所有 `audit_logs.user_id` 都會是 null，違反 A4 拍板「審計記錄納 v1」
- **修正**：在 JWT 認證 filter / Controller 解完 token 後 `MDC.put("userId", ...)`，並於 finally `MDC.clear()`
- **負責人**：Bruno（與 TD-2 Spring Security 正規化合併處理）
- **預估**：2 小時

### FE-01：http.ts 攔截器 hard reload 跳登入 + 遺失 traceId
- **檔案**：`frontend/src/services/http.ts`
- **問題**：用 `window.location.assign('/login')` 會清掉 `ProtectedRoute` 的 `from` state，使用者修完登入回不到原頁；且 401 路徑直接拋固定訊息，未從 envelope 解 traceId，違反可追蹤性
- **修正**：
  - 改用 router navigator（注入 navigate function）保留 from state
  - 從 envelope `data.traceId` 透傳到 BusinessError
- **負責人**：Felix
- **預估**：1.5 小時
